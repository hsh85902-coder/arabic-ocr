# المستخرج الذكي OCR — Flutter Android v0.2

تطبيق Flutter فعلي المصدر لأندرويد، بواجهة عربية RTL، لاختيار الصور وملفات PDF، والتصوير بالكاميرا، واستخراج النص عبر Tesseract محلياً أو خادم OCR اختياري.

## ما يعمل في هذه النسخة المصدرية
- تصوير مستند بالكاميرا.
- اختيار PDF وصور JPG/PNG/TIFF/BMP/WEBP.
- تحويل صفحات PDF إلى صور ومعالجتها صفحة بصفحة محلياً.
- OCR محلي عبر Tesseract باللغتين العربية والإنجليزية.
- وضع هجين: يحاول الخادم أولاً لملف PDF (ليستخرج النص الرقمي الأصلي ويعالج الصفحات المصورة)، مع fallback محلي عند تعذر الاتصال. وللصور يجرب Tesseract ثم الخادم عند انخفاض النص/تعذر المحرك.
- تعديل النص المستخرج داخل التطبيق، وتصديره/مشاركته كملف TXT.
- إعداد عنوان API لخادم FastAPI السابق، المتوافق مع `/api/extract`.

## متطلبات قبل البناء
1. Flutter SDK حديث وAndroid SDK على جهاز تطوير.
2. تنزيل `ara.traineddata` و`eng.traineddata` من tessdata_best ووضعهما في `assets/tessdata/`.
3. توليد ملفات Android الأصلية بأمر `flutter create` حسب `android_app_setup.txt`.
4. تشغيل `flutter pub get` ثم `flutter build apk --release`.

## تشغيل الخادم الهجين
استخدم خادم FastAPI من مشروع `arabic_ocr_app` السابق، وثبّت PaddleOCR واضبط `GOOGLE_CLOUD_VISION_API_KEY` اختيارياً على الخادم فقط. لا تضع مفتاح Google في تطبيق الهاتف.

عنوان الخادم المدخل في التطبيق يجب أن يكون عنوان HTTPS عاماً أو عنواناً محلياً يمكن للهاتف الوصول إليه، من دون `/api/extract` في النهاية. مثال: `https://ocr.example.com`.

## بناء APK
راجع `android_app_setup.txt`. بعد إعداد Android platform وتشغيل أوامر البناء سيكون APK في:
`build/app/outputs/flutter-apk/app-release.apk`

## حدود النسخة 0.2
- لم يُرفق ملف `ara.traineddata` بسبب حجمه وترخيص/توزيع ملفات النماذج؛ يجب تنزيله منفصلاً.
- لم يتم بناء APK أو اختباره على جهاز Android في بيئة الإنشاء الحالية لعدم توفر Flutter SDK/Android SDK.
- التصدير الحالي TXT؛ تصدير DOCX/PDF من التطبيق، ومعاينة الصفحة ومربعات الكلمات، وتحسين ترتيب الجداول، وإدارة الثقة لكل كلمة، ضمن الإصدارات التالية.
- Tesseract محلياً لا يوفر في هذه النسخة درجات ثقة أو صناديق مواضع الكلمات من واجهة الحزمة المستخدمة؛ الخادم PaddleOCR يتيح بيانات مواضع/ثقة في واجهة الويب السابقة، وسيتم ربطها في إصدار لاحق.

## خصوصية
المعالجة المحلية لا ترسل المستند إلى الإنترنت. في وضع الهجين لا يرسل الملف إلا عند إدخال عنوان خادم واختيار وضع هجين/سحابي. شغّل الخادم على HTTPS واحمِه بالمصادقة قبل استخدامه مع ملفات موكلين.
